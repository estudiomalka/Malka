# Malka CRM

El panel de Estudio Malka: un plugin de WordPress hecho a medida, que vive en
`estudiomalka.cl/escritorio/`.

Este repositorio existe para una sola cosa: **publicar las versiones**. Cada
release trae el ZIP del plugin, y el panel instalado lo ve solo y lo ofrece en
Plugins → Actualizaciones, como cualquier otro plugin. Se acabó bajar un ZIP,
subirlo a mano y recargar.

## Cómo se actualiza

1. En el panel: **Configuración → Actualizaciones**, con el repositorio puesto
   (`estudiomalka/malka`) y la llave de lectura guardada.
2. WordPress avisa cuando hay una versión nueva.
3. Un clic en **Actualizar**.

La llave se guarda en el sitio y nunca se escribe acá.

## El código

- `malka-crm/` — el plugin entero, tal cual se instala.
